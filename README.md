# Global-Job-Market-Layoffs-Dashboard-Power-BI-Tableau-Qlik-Sense
This dashboard analyzes the impact of AI Automation, hiring trends, fresher opportunities, skill demand, job growth, and startup employment in the IT sector.

🔍 Key Insights:
✅ AI & Automation adoption trends
✅ Fresher vs Experienced hiring analysis
✅ Job growth vs automation risk
✅ In-demand skills: AI/ML, Data Engineering, Cloud, Cybersecurity, Power BI & Python
✅ Startup job creation trends
✅ 2025 vs 2026 market comparison


🛠️ Tools & Technologies:
Power BI | Tableau | Qlik Sense | QlikView | DAX | SQL | Python | CRM | ERP | AI Automation

🎯 The goal of this project is to understand how the IT job market is changing and identify the skills and roles that will drive future opportunities.
📈 Data-driven insights. Better career decisions. Future-ready skills.
